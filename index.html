AI runtime

Bring your preferred AI key. Keep Ollama ready as backup.

Walker OS is planned around a provider-flexible brain: use a primary API model such as OpenAI, Gemini, or another compatible service when keys are available, then fall back to Ollama for local models, privacy mode, outages, or low-cost offline operation.

Editions

Walker OS Lite for small hardware. Walker OS Full for local power.

The same assistant can ship in two profiles: a cloud-assisted Lite image for Raspberry Pi-class devices, and a Full image for hardware that can keep memory, files, indexing, and heavier services on-device.

Walker OS Lite

Cloud-assisted, low-footprint image

Built for limited RAM and storage. Lite keeps the local dashboard, wake/input layer, secure tunnels, device control, and basic memory locally, then offloads bulk files, backups, transcripts, and indexes to a chosen cloud such as Nextcloud, Google Drive, iCloud, Dropbox, or business storage.

Walker OS Full

Local-first image with cloud as an option

Built for Pi 5, mini PCs, desktops, servers, and homelabs. Full can do everything Lite does, but keeps larger memory stores, files, search indexes, automations, and backups on local hardware unless the user chooses cloud sync.
